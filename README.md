# BAB I

# PENDAHULUAN

## 1.1 Deskripsi Sistem

Website Monitoring BUMDes merupakan sistem berbasis web yang dikembangkan untuk membantu Bidang Pengembangan Usaha Ekonomi Masyarakat (PUEM) dalam melakukan pendataan dan monitoring data Badan Usaha Milik Desa (BUMDes).

Sistem menyediakan fasilitas pengelolaan data BUMDes, wilayah kecamatan dan desa, informasi usaha, status, peringkat, legalitas, serta data petugas BUMDes. Selain itu, sistem menyediakan dashboard yang menampilkan informasi dalam bentuk ringkasan dan grafik sehingga data dapat dipantau dengan lebih mudah.

Sistem juga menyediakan fasilitas export data BUMDes ke dalam format Excel untuk mendukung kebutuhan pengolahan dan pelaporan data.

## 1.2 Tujuan Sistem

Website Monitoring BUMDes dikembangkan dengan tujuan untuk:

1. Membantu proses pendataan BUMDes secara terstruktur.
2. Mempermudah petugas dalam melakukan pengelolaan dan pembaruan data.
3. Mempermudah pencarian dan penyaringan data BUMDes.
4. Menyediakan informasi ringkas mengenai kondisi data BUMDes melalui dashboard.
5. Mengurangi ketergantungan terhadap pengelolaan data secara manual.
6. Mempermudah penyediaan data melalui fasilitas export ke Excel.

## 1.3 Manfaat Sistem

Manfaat yang diperoleh dari penggunaan sistem antara lain:

1. Data BUMDes dapat dikelola dalam satu sistem.
2. Proses pencarian data menjadi lebih mudah.
3. Informasi BUMDes dapat ditampilkan secara terstruktur.
4. Monitoring data dapat dilakukan melalui dashboard.
5. Data dapat diperbarui sesuai kebutuhan.
6. Data dapat diekspor untuk kebutuhan pengolahan dan pelaporan.

## 1.4 Ruang Lingkup

Ruang lingkup Website Monitoring BUMDes meliputi:

* Pengelolaan data BUMDes.
* Pengelolaan data kecamatan.
* Pengelolaan data desa.
* Pengelolaan sektor usaha.
* Pengelolaan jenis usaha.
* Pengelolaan status BUMDes.
* Pengelolaan peringkat BUMDes.
* Pengelolaan data legalitas BUMDes.
* Pengelolaan data petugas/pengurus BUMDes.
* Penyajian informasi melalui dashboard.
* Export data BUMDes.
* Pengelolaan pengguna berdasarkan hak akses.

# BAB IV

# PANDUAN PENGGUNAAN SISTEM

## 4.1 Mengakses Sistem

Website Monitoring BUMDes dapat diakses melalui browser.

### Langkah-langkah:

1. Buka browser.

2. Masukkan alamat website:

   **https://puem.vercel.app/login.html**

3. Tekan **Enter**.

4. Sistem akan menampilkan halaman Login.

5. Pengguna dapat melakukan login menggunakan akun yang telah diberikan.

---

## 4.2 Login

Login digunakan untuk melakukan autentikasi pengguna sebelum dapat mengakses sistem.

### Langkah-langkah:

1. Buka halaman Website Monitoring BUMDes.
2. Masukkan **Username**.
3. Masukkan **Password**.
4. Tekan tombol **Login**.
5. Sistem akan melakukan pemeriksaan terhadap data akun.
6. Jika data benar, pengguna diarahkan ke halaman Dashboard.
7. Jika data salah, sistem menampilkan pemberitahuan bahwa proses login gagal.

### Kondisi Login Berhasil

Setelah login berhasil, sistem akan menampilkan halaman Dashboard sesuai dengan hak akses pengguna.

---

# 4.3 Dashboard

Dashboard merupakan halaman utama sistem yang memberikan gambaran umum mengenai data BUMDes.

Dashboard menampilkan beberapa informasi utama, antara lain:

### 4.3.1 Total BUMDes

Menampilkan jumlah keseluruhan BUMDes yang telah terdaftar di dalam sistem.

### 4.3.2 Total Desa

Menampilkan jumlah desa yang terdapat pada sistem.

### 4.3.3 Total Kecamatan

Menampilkan jumlah kecamatan yang terdapat pada sistem.

### 4.3.4 Distribusi Peringkat BUMDes

Grafik digunakan untuk memberikan gambaran mengenai distribusi BUMDes berdasarkan peringkat yang telah ditentukan.

### 4.3.5 Distribusi Sektor Usaha

Menampilkan persebaran BUMDes berdasarkan sektor usaha yang dijalankan.

### 4.3.6 Distribusi Jenis Usaha

Menampilkan persebaran BUMDes berdasarkan jenis usaha yang dijalankan.

### 4.3.7 Jumlah BUMDes per Kecamatan

Grafik menampilkan jumlah BUMDes berdasarkan wilayah kecamatan.

### 4.3.8 Aktivitas Terbaru

Menampilkan informasi aktivitas terbaru yang terjadi pada sistem.

### 4.3.9 Data Belum Lengkap

Menampilkan data BUMDes yang masih memiliki informasi yang belum lengkap sehingga dapat digunakan sebagai bahan monitoring dan tindak lanjut.

---

# 4.4 Menu BUMDes

Menu BUMDes digunakan untuk melihat dan mengelola data BUMDes.

Pada halaman ini tersedia:

* Pencarian data.
* Filter kecamatan.
* Tabel data BUMDes.
* Tombol tambah data.
* Tombol detail.
* Tombol edit.
* Tombol hapus.
* Pagination.

## 4.4.1 Melihat Data BUMDes

Data BUMDes ditampilkan dalam bentuk tabel.

Informasi utama yang ditampilkan meliputi:

* Nama BUMDes.
* Desa.
* Kecamatan.
* Status.
* Sektor usaha.
* Jenis usaha.
* Aksi.

Pengguna dapat berpindah halaman menggunakan fitur pagination apabila jumlah data lebih banyak dari jumlah data yang ditampilkan pada satu halaman.

## 4.4.2 Mencari Data BUMDes

Fitur pencarian digunakan untuk menemukan data BUMDes dengan lebih cepat.

### Langkah:

1. Masuk ke menu **BUMDes**.
2. Klik kolom pencarian.
3. Masukkan nama atau informasi yang ingin dicari.
4. Sistem akan menampilkan data yang sesuai dengan kata pencarian.

## 4.4.3 Filter Kecamatan

Filter kecamatan digunakan untuk menampilkan data BUMDes berdasarkan kecamatan tertentu.

### Langkah:

1. Buka menu **BUMDes**.
2. Pilih kecamatan pada filter.
3. Sistem akan menampilkan data BUMDes sesuai kecamatan yang dipilih.

## 4.4.4 Menambahkan Data BUMDes

Fitur tambah digunakan untuk memasukkan data BUMDes baru.

### Langkah:

1. Buka menu **BUMDes**.
2. Tekan tombol **Tambah BUMDes**.
3. Form tambah data akan ditampilkan.
4. Isi data BUMDes sesuai informasi yang tersedia.
5. Masukkan data wilayah seperti desa.
6. Masukkan status BUMDes.
7. Masukkan sektor dan jenis usaha.
8. Masukkan informasi legalitas apabila tersedia.
9. Masukkan informasi pengurus/petugas BUMDes.
10. Periksa kembali data yang telah dimasukkan.
11. Tekan tombol **Simpan**.
12. Sistem akan menyimpan data.

## 4.4.5 Melihat Detail BUMDes

Fitur detail digunakan untuk melihat informasi BUMDes secara lebih lengkap.

### Langkah:

1. Buka menu **BUMDes**.
2. Cari data BUMDes yang ingin dilihat.
3. Tekan tombol **Detail/Lihat**.
4. Sistem menampilkan informasi lengkap BUMDes.

Informasi yang dapat ditampilkan meliputi:

* Identitas BUMDes.
* Wilayah.
* Kontak.
* Status.
* Peringkat.
* Sektor usaha.
* Jenis usaha.
* Legalitas.
* Data pengurus/petugas.

## 4.4.6 Mengubah Data BUMDes

Fitur edit digunakan untuk memperbarui data yang telah tersimpan.

### Langkah:

1. Cari data BUMDes.
2. Tekan tombol **Edit**.
3. Sistem menampilkan formulir data.
4. Ubah informasi yang diperlukan.
5. Periksa kembali perubahan.
6. Tekan tombol **Simpan/Update**.
7. Sistem memperbarui data.

## 4.4.7 Menghapus Data BUMDes

Fitur hapus digunakan untuk menghapus data BUMDes yang sudah tidak diperlukan.

### Langkah:

1. Cari data BUMDes.
2. Tekan tombol **Hapus**.
3. Sistem menampilkan konfirmasi penghapusan.
4. Periksa kembali data yang akan dihapus.
5. Pilih **Konfirmasi** jika data benar-benar akan dihapus.
6. Sistem menghapus data.

**Catatan:** Penghapusan data harus dilakukan dengan hati-hati karena dapat menghilangkan data dari sistem.

# 4.7 Menu Admin

Menu Admin digunakan oleh pengguna dengan role **Admin** untuk mengelola akun pengguna.

Admin dapat melakukan:

* Melihat daftar pengguna.
* Menambahkan pengguna.
* Mengubah data pengguna.
* Menghapus pengguna.

Role yang digunakan dalam sistem:

* Admin.

3. Masukkan username.

---

# 4.8 Menu Export

Menu Export digunakan untuk menghasilkan data BUMDes dalam bentuk file Excel.

### Langkah Export:

1. Buka menu **Export**.
2. Tekan tombol **Export Data**.
3. Sistem memproses data BUMDes.
4. File Excel akan dihasilkan.
5. Simpan file pada perangkat.

Format file yang dihasilkan adalah:

**`.xlsx`**

File tersebut dapat dibuka menggunakan Microsoft Excel atau aplikasi spreadsheet yang mendukung format Excel.

# 4.9 Logout

Logout digunakan untuk keluar dari sistem.

### Langkah:

1. Tekan menu **Logout**.
2. Sistem menampilkan konfirmasi.
3. Pilih **Konfirmasi Logout**.
4. Sistem mengakhiri sesi pengguna.
5. Pengguna diarahkan kembali ke halaman login.

# BAB V

# PENANGANAN KESALAHAN

## 5.1 Login Gagal

Apabila username atau password yang dimasukkan tidak sesuai, sistem akan menampilkan pemberitahuan bahwa login gagal.

### Solusi:

* Pastikan username benar.
* Pastikan password benar.
* Periksa penggunaan huruf besar dan kecil.
* Coba login kembali.

## 5.2 Data Tidak Ditemukan

Jika pencarian tidak menemukan data, sistem akan menampilkan kondisi tidak adanya data yang sesuai.

### Solusi:

* Periksa kata pencarian.
* Hapus filter yang sedang digunakan.
* Coba gunakan kata pencarian yang lebih sederhana.

## 5.3 Data Belum Lengkap

Data yang belum memiliki informasi tertentu dapat ditampilkan pada bagian **Data Belum Lengkap** di Dashboard.

Pengguna dapat membuka data tersebut dan melengkapi informasi yang diperlukan melalui fitur **Edit**.

## 5.4 Gagal Menyimpan Data

Apabila data gagal disimpan:

1. Periksa apakah seluruh data wajib telah diisi.
2. Periksa format data yang dimasukkan.
3. Pastikan koneksi internet stabil.
4. Coba simpan kembali.
5. Jika masalah tetap terjadi, hubungi administrator sistem.

## 5.5 Gagal Menghapus Data

Apabila data gagal dihapus:

1. Pastikan pengguna memiliki hak akses untuk menghapus data.
2. Periksa koneksi internet.
3. Coba ulangi proses penghapusan.
4. Jika masalah tetap terjadi, hubungi administrator sistem.

## 5.6 Gangguan Koneksi

Jika halaman tidak dapat dimuat atau sistem tidak merespons:

1. Periksa koneksi internet.
2. Refresh halaman.
3. Coba membuka sistem kembali.
4. Jika sistem tetap tidak dapat diakses, hubungi administrator.
